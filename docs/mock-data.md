# Mock 데이터 카탈로그

> 해커톤 데모용 가상 데이터다. 실제 기사·차량·운임·연락처와 무관하며, 외부 서비스나 실제 인물 정보로 사용하지 않는다.

## 사용 원칙

- 이 문서는 백엔드 seed·프론트 목업·발표 시나리오의 **공통 기준 데이터**다.
- `docs/openai-direct-curl.md`의 OpenAI 직접 호출은 비용 절감을 위해 아래 전체 데이터가 아닌 소형 3기사 세트만 넣는다.
- 실제 앱 랭킹은 모든 적격 화물을 점수화한 뒤 `page=0&size=20`으로 자른다. 아래 데이터는 20건 초과·2페이지·낮은 운임·차종 불일치까지 검증할 수 있게 구성했다.
- 금액 단위는 원화(KRW), 중량 단위는 톤(t), 일시는 KST다.

## 4. 필수 데모 시나리오

| 시나리오 | 데이터 | 기대 결과 |
|---|---|---|
| 운임 경고 + 최적 추천 | `freight-001` | 평균 72만원 대비 낮음 경고, `driver-01` 최상위 후보 |
| 적정 운임 | `freight-002` | `FAIR`, `driver-01` 후보 |
| 최소수락운임 미달 | `freight-044` | `driver-01`(42만원) 후보 제외 |
| 차종 불일치 | `freight-043` | 냉동만 가능한 기사만 후보 |
| 20건 초과 페이지 | `driver-01` + 서울→부산 일반/냉장 화물 | `page=0,size=20` 뒤 `hasNext=true` 확인 |
| 시세 없음 | 새 구간·화물종류 조합 | `UNKNOWN`, 오류 없이 매칭 계속 |
| 활동지역 수정 | `driver-01`의 선호 목적지를 부산 강서→해운대로 변경 | 해운대 도착 화물의 랭킹 상승 |
