# 카카오모빌리티 물류 해커톤 — 작업 요약

**팀명**: 집나간 벌꿀오소리
**본선 일정**: 이번주 목요일 09:00~18:00

---

## 1. 선정 주제

**화물 다단계 브로커리지 투명화**
화주가 카톡/전화/엑셀로 보낸 비정형 화물요청을 LLM이 자동 구조화하고, 다단계 브로커 없이 차주와 직접 매칭 추천, 운임이 시세보다 비정상적으로 낮으면 경고하는 서비스.

- 팀 구성: 백엔드2 · 프론트2 · 기획1
- 핵심 기능: ① 파싱 ② 매칭 ③ 운임 검증
- 결과물: 웹앱 (화주 페이지 / 기사 페이지 2개 화면)
- 기사 등록화면은 제외 (mock 차주 데이터 전제)

---

## 2. 팀 캐릭터

'집나간 벌꿀오소리' 컨셉으로 보따리를 멘 채 걷는 벌꿀오소리 캐릭터를 제작 (팀 프로필 이미지용). 이후 팀에서 별도로 이미지를 제작해 최종 로고로 확정, 와이어프레임 상단 브랜딩에 적용함.

---

## 3. 와이어프레임 — 화주 페이지

| 영역 | 내용 |
|---|---|
| 좌측 상단 | 로고 이미지 + "집나간 벌꿀오소리" 팀명 |
| 01 · 화물 요청 입력 | 카톡/전화 텍스트 입력 → "AI 자동 변환" 버튼 |
| 02 · AI 변환 결과 | 출발지/도착지/화물종류/중량/희망운임/상차일시/하차일시 (필드별 직접 수정 가능) · "재매칭 / 수정하기" 버튼 |
| 운임 경고 배너 | 제시 운임이 구간 평균보다 낮을 경우 경고 문구 노출 |
| 03 · 매칭 기사 | 최종 매칭 1건 (목록 아님) — 기사명/차량/차량번호/운행지역/평점/완료율/최근 운행/연락 가능 시간/최소수락운임/선호 지역(도착지) 표시 · "전화하기" 버튼 |

**매칭 로직 논의**
실시간 경매(입찰) 방식은 해커톤 시간·구현 배점(10%) 대비 리스크가 커서 배제. 대신 기사 mock 프로필에 `최소수락운임` 필드를 두고, ① 화물종류 필터 → ② 출발지 거리순 정렬 → ③ 제시 운임이 최소수락운임 이상인지 확인 후 근접도로 스코어링하는 방식을 제안.

## 4. 와이어프레임 — 기사 페이지

| 영역 | 내용 |
|---|---|
| 활동 지역 설정 | 출발지/도착지 각각 1차(시/도) · 2차(시/군/구) 선택박스, 최초 등록 후 수정 가능 |
| 01 · 추천 화물 | 우측에 새로고침 아이콘 버튼, 첫 페이지 카드 최대 20건 노출 (스크롤 영역) |
| 카드 구성 | 상차/하차 태그, 화물정보, 운임비, 운임 배지(적정/낮음), 평균 운임 안내(낮음 케이스) |
| 최적 매칭 강조 | 첫 번째 카드에 강조 테두리 + "✦ 최적 매칭" 라벨 |
| 액션 버튼 | "거절" 대신 "숨기기"로 순화, "수락" 유지 |
| 내 수입 탭 | 최종적으로 삭제, 해당 공간은 추천 화물 리스트 높이로 확장 |

## 5. 기획 참고 논의 — 화주/기사 힘의 구조

물류 시장은 구조적으로 **화주 > 플랫폼/주선 > 차주** 순의 협상력을 가짐. 차주는 공차 회피 압박과 파편화된 개인사업자 구조로 협상력이 약하고, 다단계 주선 수수료가 더해져 실수령액이 줄어드는 구조. 다만 냉동·특수차량, 성수기, 벽지 구간 등에서는 차주 우위로 역전되기도 함. 이 비대칭을 줄이는 것이 이번 서비스(직접 매칭 + 운임 투명성)의 핵심 가치 제안으로 연결됨.
